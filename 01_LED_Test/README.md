# LED Test – ESP32

This project demonstrates basic LED control using an ESP32.

## Working

The LED is connected to GPIO 2 through a 330Ω resistor.

The ESP32 turns the LED ON and OFF using digital output control.

## Expected Output

The LED continuously blinks:

- LED ON
- LED OFF
- LED ON
- LED OFF

This confirms that GPIO 2 and the external LED are working correctly.

The Arduino code used for testing is available in `LED_Test.ino`.
